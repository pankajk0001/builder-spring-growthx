Can my club use it today?

The helper is in a small, invited pilot. Private setup, board review, and posting to a verified test group have been checked in WhatsApp. Join the pilot opens the helper in WhatsApp with START ready to send. Set up your club privately, save its venue and review the board before connecting your group. Real-club onboarding is available in the pilot; use a test group to check your first board.

Do I need another app?

No. The Secretary’s setup and board review happen in WhatsApp. The helper uses a separate number that you add to the test group.

What if the helper isn’t in the group?

It won’t post a new board. It asks you privately to add the helper number and reconnect. Your approved board and meeting settings stay saved.

What if a name or role is wrong?

Correct it in the private review chat. You can change the saved venue through EDIT too. The helper shows a new preview for approval. If one correction needs clarification, it keeps the valid entries while you fix that line.

Is there a payment or signup here?

No. There’s no payment or signup on this page. The current pilot is being run without additional spending; public plans and pricing have not been announced.
